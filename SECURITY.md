# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through [GitHub's security advisory interface](https://github.com/ItsMonarch04/multi-meters/security/advisories/new). Do not open a public issue for a vulnerability that could expose credentials, local data, or another user's system.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Reports will be acknowledged as soon as practical and coordinated disclosure is appreciated.

## Supported versions

Security fixes are applied to the latest release of MultiMeters.
